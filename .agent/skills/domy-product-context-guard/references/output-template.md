# Output template — Domy Product Context Guard

## Objetivo
Toda respuesta de esta skill debe seguir una estructura consistente para evaluar alineación de producto, funcionalidad o decisión.

## Plantilla obligatoria

### 1. Resumen de la propuesta
Explicar brevemente qué funcionalidad, cambio, flujo o decisión se está evaluando.

### 2. Alineación con la misión
Explicar si la propuesta fortalece o no:
- formalización
- confianza
- trazabilidad
- profesionalización del servicio

### 3. Impacto en el hogar
Explicar qué problema resuelve o qué valor crea para el hogar contratante.

### 4. Impacto en la operaria
Explicar qué problema resuelve o qué valor crea para la operaria.

### 5. Impacto en confianza y seguridad
Explicar si mejora, debilita o no afecta significativamente la arquitectura de confianza del producto.

### 6. Encaje con el MVP
Indicar si:
- refuerza una capacidad central del MVP
- reduce una fricción crítica del MVP
- está fuera de foco para el momento actual

### 7. Impacto operativo y de negocio
Explicar implicaciones sobre:
- simplicidad operativa
- crecimiento progresivo
- densidad local
- sostenibilidad del producto

### 8. Riesgos
Indicar riesgos de:
- complejidad
- pérdida de foco
- debilidad en confianza
- sobrecarga operativa
- confusión para el usuario

### 9. Recomendación final
Cerrar con una conclusión clara:
- aprobar
- aprobar con ajustes
- postergar
- rechazar por desalineación

## Reglas de calidad
La respuesta debe:
- evitar opiniones vagas
- conectar la evaluación con el propósito de Domy
- distinguir entre valor real y complejidad aparente
- señalar riesgos concretos
- terminar con una recomendación accionable
