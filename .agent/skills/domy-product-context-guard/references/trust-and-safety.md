# Trust and safety — Domy App

## Objetivo
Definir los principios de confianza y seguridad que deben guiar cualquier funcionalidad, flujo o decisión de producto dentro de Domy.

## Principio central
En Domy, la confianza no es una mejora opcional. Es parte del producto central.

## Problema de base
El hogar enfrenta una barrera emocional y práctica importante: permitir el ingreso de una persona externa al hogar.  
La operaria, por su parte, necesita un entorno profesional y verificable que proteja su reputación y reduzca arbitrariedad.

## Arquitectura de confianza
Domy debe construir confianza mediante una combinación de:
- verificación rigurosa
- historial visible
- reputación trazable
- claridad operativa
- soporte integrado
- transparencia económica

## Componentes clave de confianza

### Verificación
Debe existir evidencia visible de validación de identidad o estado de verificación.

### Trayectoria
El sistema debe permitir comprender experiencia, historial o contexto reputacional relevante.

### Calificaciones comunitarias
La reputación debe ser visible, comprensible y útil para reducir incertidumbre.

### Soporte en la app
Debe existir un mecanismo claro para resolver problemas, dudas o incidentes sin salir del flujo del producto.

### Transparencia previa a la confirmación
Ningún costo importante debe percibirse como sorpresa.

## Señales de una buena feature de confianza
- reduce incertidumbre
- mejora percepción de seguridad
- aumenta trazabilidad
- da contexto útil para decidir
- reduce miedo o fricción crítica
- mejora capacidad de resolver incidentes

## Señales de una mala feature
- oculta información relevante
- aumenta opacidad
- introduce pasos sin valor visible
- complica el flujo sin aumentar confianza real
- delega seguridad al usuario sin apoyo del sistema

## Regla de producto
Cuando una decisión genere conflicto entre velocidad y confianza, priorizar confianza si el impacto toca seguridad, validación o percepción de riesgo.

## Regla final
Si una propuesta no fortalece la arquitectura de confianza o la debilita indirectamente, debe revisarse con alto nivel de exigencia.
